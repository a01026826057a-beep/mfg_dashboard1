ARDUINO PROJECT NOTES

신호등 제어 & 기상나팔 부저

버튼으로 신호등 동작을 제어하고, 초록불이 켜지면 부저가 기상나팔풍 멜로디를 재생하는 프로젝트를 정리했습니다.

프로젝트 개요

무엇을 만들었나요?

🚦 자동 신호등빨강·노랑·초록 LED가 정해진 시간에 따라 바뀝니다.
🔘 버튼 제어버튼을 누르면 초록불이 될 때까지 기다렸다가 음악을 시작합니다.
🎺 부저 멜로디패시브 부저로 기상나팔풍 음계를 재생합니다.

부품 및 핀 연결

부품아두이노 핀설명
빨간 LEDD9빨간불 출력
노란 LEDD10노란불 출력
초록 LEDD11초록불 출력
푸시 버튼D2INPUT_PULLUP 사용. 버튼 반대쪽은 GND에 연결
패시브 부저D8음 높이를 바꿔 멜로디 재생
공통 접지GND회로의 접지를 공유

LED마다 전류 제한 저항(일반적으로 220–330Ω)을 직렬로 연결하세요.

작동 순서

  1. 전원을 켜면 빨간불부터 시작합니다.
  2. 신호등은 빨강 3초, 노랑 1초, 초록 3초 간격으로 순환합니다.
  3. 대기 중 버튼을 한 번 누르면 다음 초록불이 켜질 때까지 기다립니다.
  4. 초록불이 켜지면 부저가 멜로디를 시작하고 최대 30초 동안 반복합니다.
  5. 재생 중 버튼을 다시 누르면 부저를 끄고 빨간불로 초기화합니다.
  6. 30초가 지나도 음악이 종료되고 빨간불로 돌아갑니다.
참고: 음악이 재생되는 동안 신호등은 초록불로 유지됩니다. 재생 종료 시 빨간불로 돌아갑니다.

기상나팔 멜로디

사용자가 제공한 「기상나팔(Reveille)」 악보 이미지를 참고해 숫자 계이름을 부저 주파수로 근사 변환했고, 요청에 따라 음역을 높였습니다.

정확도 안내
이미지의 음표와 붙임줄이 작아 모든 음정과 리듬을 정확히 판독한 것은 아닙니다. 따라서 현재 멜로디는 원곡과 완전히 일치하지 않는 근사 버전입니다. 정확한 리듬을 위해서는 선명한 악보를 확인하고 음 길이·쉼표·붙임줄을 개별적으로 입력해야 합니다.

부저의 한계

  • 패시브 부저는 한 번에 한 음을 내므로 트럼펫의 음색이나 녹음 음원을 재현할 수 없습니다.
  • 음정은 주파수(Hz), 리듬은 음 길이(밀리초)로 지정합니다.
  • 실제 음원을 재생하려면 DFPlayer Mini 같은 MP3 모듈과 스피커를 사용하는 방법이 적합합니다.

현재 통합 코드

신호등·버튼·부저 구조와 높은 음역의 기상나팔풍 멜로디를 한 파일로 정리한 예시입니다. 리듬은 악보 이미지에 대한 근사치입니다.

const int redPin = 9;
const int yellowPin = 10;
const int greenPin = 11;
const int buttonPin = 2;
const int buzzerPin = 8;

// 기상나팔풍 멜로디: 높은 음역 버전. 0은 쉼표.
const int melody[] = {
  784, 698, 698, 698, 698,
  784, 698, 659, 698, 784, 698, 659,
  698, 784, 698, 698, 659,
  698, 784, 784, 698, 659, 698,
  698, 784, 784, 698, 659,
  698, 784, 698, 659, 698,
  784, 698, 698, 659, 698,
  659, 659, 659, 659, 0,
  784, 784, 698, 659, 698,
  659, 659, 698, 784, 784,
  698, 659, 698, 784, 698,
  659, 698, 784, 698, 659
};

const int noteDuration[] = {
  430, 430, 430, 430, 430,
  430, 430, 430, 430, 430, 430, 430,
  430, 430, 430, 430, 430,
  430, 430, 430, 430, 430, 860,
  430, 430, 430, 430, 430,
  430, 430, 430, 430, 430,
  430, 430, 430, 430, 860,
  430, 430, 430, 430, 430,
  430, 430, 430, 430, 860,
  430, 430, 430, 430, 430,
  430, 430, 430, 430, 430,
  430, 430, 430, 430, 860
};

const int noteCount = sizeof(melody) / sizeof(melody[0]);
int lightState = 0;
bool lastButtonState = HIGH;
bool waitingForGreen = false;
bool musicMode = false;
bool notePlaying = false;
unsigned long lightTimer = 0;
unsigned long musicStart = 0;
unsigned long noteTimer = 0;
int noteIndex = 0;

void setup() {
  pinMode(redPin, OUTPUT);
  pinMode(yellowPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(buttonPin, INPUT_PULLUP);
  pinMode(buzzerPin, OUTPUT);
  setLight();
  lightTimer = millis();
}

void loop() {
  updateButton();
  if (!musicMode) updateTrafficLight();

  if (waitingForGreen && lightState == 2) {
    waitingForGreen = false;
    musicMode = true;
    musicStart = millis();
    noteIndex = 0;
    notePlaying = false;
    noteTimer = millis();
  }

  if (musicMode) updateMusic();
}

void setLight() {
  digitalWrite(redPin, lightState == 0 ? HIGH : LOW);
  digitalWrite(yellowPin, lightState == 1 ? HIGH : LOW);
  digitalWrite(greenPin, lightState == 2 ? HIGH : LOW);
}

void updateTrafficLight() {
  unsigned long now = millis();
  unsigned long duration = (lightState == 1) ? 1000UL : 3000UL;
  if (now - lightTimer >= duration) {
    lightState = (lightState + 1) % 3;
    setLight();
    lightTimer = now;
  }
}

void updateButton() {
  bool current = digitalRead(buttonPin);
  if (lastButtonState == HIGH && current == LOW) {
    if (!waitingForGreen && !musicMode) {
      waitingForGreen = true;
    } else {
      waitingForGreen = false;
      musicMode = false;
      noTone(buzzerPin);
      lightState = 0;
      setLight();
      lightTimer = millis();
    }
  }
  lastButtonState = current;
}

void updateMusic() {
  unsigned long now = millis();
  if (now - musicStart >= 30000UL) {
    noTone(buzzerPin);
    musicMode = false;
    lightState = 0;
    setLight();
    lightTimer = millis();
    return;
  }
  if (now < noteTimer) return;

  if (notePlaying) {
    noTone(buzzerPin);
    notePlaying = false;
    noteIndex++;
    if (noteIndex >= noteCount) noteIndex = 0;
    noteTimer = millis() + 30;
  } else {
    if (melody[noteIndex] == 0) noTone(buzzerPin);
    else tone(buzzerPin, melody[noteIndex]);
    notePlaying = true;
    noteTimer = millis() + noteDuration[noteIndex];
  }
}
